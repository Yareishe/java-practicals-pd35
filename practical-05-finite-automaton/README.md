# Практична робота №5 — скінченний автомат для слова TEST

Програма читає рядок посимвольно й повертає найдовший стан збігу з префіксом `TEST`: `S` (збігу немає), `1` (`T`), `2` (`TE`), `3` (`TES`) або `F` (слово знайдено). Пошук чутливий до регістру. Після входу в `F` автомат залишається в цьому стані.

У реалізації враховані перекриття часткового збігу. Наприклад, після `TT` стан має бути `1`, а після `TET` — теж `1`, бо остання літера може бути початком нового `TEST`. Наївний перехід до `S` у цих ситуаціях пропускає входження `TEST` у `TTEST` та `TETEST`.

## Запуск

Потрібні JDK 17+ і Maven 3.8+. Із цієї папки виконайте:

- `mvn test`
- `mvn exec:java`

Програма запросить рядок і покаже кінцевий стан. JUnit 5 використовує параметризовані тести для результатів рядків і окремі параметри для переходів станів, зокрема випадків перекриття.
