# Java практичні роботи — ПД-35

Збірка робіт Єфіменка Максима Олександровича для курсу «Конструювання програмного забезпечення Java».

## Практична №1 — Основи Java

Консольний інтернет-магазин: каталог категорій і товарів, кошик, оформлення замовлення, пошук та історія замовлень.

- Проєкт: practical-01-java-basics/
- Запуск із каталогу проєкту: mvn clean package, потім mvn exec:java
- Звіт: practical-01-java-basics/docs/Звіт_ПР1_Основи_Java.pdf

## Практична №2 — ООП

Фінансовий аналізатор CSV: загальний баланс, транзакції за місяцем, 10 найбільших витрат, найбільша/найменша витрати, витрати за категоріями й місяцями.

- Проєкт: practical-02-finance-analyzer/
- Звіт: practical-02-finance-analyzer/docs/Звіт_ПР2_Фінансовий_аналізатор.pdf
- Запуск і тести: перейдіть у каталог проєкту; виконайте mvn test та mvn exec:java
- Вихідний CSV із методички та локальний резервний CSV включені до проєкту.

Обидва проєкти потребують JDK 17+ та Maven 3.8+. Код і звіти не були завантажені до Classroom. Перевірте завдання в IDE перед здачею: локальне середовище підготовки не мало JDK/Maven, тому Java-проєкти та JUnit-тести тут не запускалися.
