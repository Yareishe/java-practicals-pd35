# Практична робота — Calculator (Java)

Клас Calculator реалізує додавання, віднімання, множення та ділення двох чисел типу double. Ділення на нуль спричиняє ArithmeticException. Вхідні значення NaN та нескінченність відхиляються через InvalidInputException; текст, який не перетворюється на число, теж дає зрозуміле повідомлення про помилку.

Main запитує два числа й оператор (+, -, *, /), виконує обчислення у try-catch-finally та завжди виводить повідомлення про завершення запиту.

## Запуск

Потрібні JDK 17+ та Maven 3.8+. Виконайте з цієї папки:

- mvn test
- mvn exec:java

## Тести

JUnit 5 перевіряє чотири операції, ділення на нуль, NaN/нескінченні вхідні значення, текст замість числа та невідому операцію.
