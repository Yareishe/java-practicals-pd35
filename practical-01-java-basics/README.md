# Практична робота №1 — Основи Java

**Проєкт:** консольний інтернет-магазин  
**Виконав:** Єфіменко Максим Олександрович, ПД-35  
**Викладач курсу:** Шахматов Іван Олександрович

## Функції

- перегляд каталогу товарів і категорій;
- додавання товарів до кошика та перегляд підсумку;
- повне видалення позиції з кошика;
- пошук за назвою/описом або категорією без урахування регістру;
- оформлення замовлення зі знімком ціни й кількості;
- перегляд історії замовлень поточного запуску.

Класи `Product` і `Category` мають інкапсульовані поля, конструктори, гетери, сетери та перевизначений `toString()`. Lombok генерує гетери, сетери та конструктори без аргументів. Клас `Order` фіксує склад, суму, дату й статус замовлення. Гроші представлені типом `BigDecimal`.

## Запуск

Потрібні JDK 17+ та Maven 3.8+. Відкрийте термінал у корені проєкту:

```text
mvn clean package
mvn exec:java
```

Maven завантажить Lombok та плагіни з Maven Central. Для IDE потрібно ввімкнути обробку анотацій (annotation processing).
